# Contributing

Thanks for contributing to NexDesk.

1. Fork the repository and create a feature branch.
2. Copy `.env.example` to `.env`; do not commit it.
3. Install dependencies with `npm install`.
4. Make the smallest scoped change that solves the issue.
5. Run `npm test` and `npm run build` before opening a pull request.
6. Explain user-visible behavior, tests run, and any deployment changes in the pull request.

Do not commit real user data, OAuth credentials, Worker secrets, exported cookies, or local databases.
